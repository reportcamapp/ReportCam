# 报料相机 ReportCam

> 时间，烧进画面里。

一款面向日常出行场景的**极简取证相机**——适合所有需要「画面自带可信时间」的时刻。

只做三件事：

1. 全屏预览后置主摄；
2. 单段录制，**把时间实时烧录进视频画面**——不是屏幕叠加的字幕，是编码进每一帧像素里；
3. 输出未经任何二次处理的原始 MP4——时间已永久写入画面，可用于任何需要时间佐证的场合。

**无广告 · 无订阅 · 无账号 · 不上传任何数据**

## 为什么做这个

很多场合都需要「画面里自带可信时间」：日常记录、工作留痕、现场情况留存、向有关部门反映情况时举证……普通相机拍出的画面没有醒目的时间，事后说不清「这是什么时候拍的」，材料就打了折扣。

本应用只专注解决这一件事：录制时把当前时间实时烧录进画面，单段原封不动写入相册，无任何后处理。所见即所得——你在预览里看到的，就是最终写进视频里的。

画面里的时间按北京时间格式化，且应用内没有任何修改时间的入口——这就是「可信」的底气。至于拿它记录什么，由你自己决定。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 时间烧录 | 每帧实时绘制 `yyyy-MM-dd HH:mm:ss`（北京时间），随编码进像素，转发/提交后依然存在；应用不提供任何修改时间的入口 |
| 黑边白字 · 智能反色 | 水印自动检测画面亮度切换字色，强光、逆光、霓虹下都可读 |
| 位置水印（可选） | 主动开启后把位置文字烧进画面第二行，关闭即停止定位 |
| 画质面板 | 按设备真实能力列出分辨率 × 帧率组合（1080P / 4K / 60fps 等），选什么录什么 |
| 真实变焦档位 | 变焦倍数来自设备物理镜头换算，录制中可随时拉近（取证时看车牌是刚需） |
| 画面口号（可选） | 左下角烧录一句自定义文案，与时间水印对角呼应 |
| 界面颜色 | 深色 / 浅色 / 跟随系统 |

## 使用提示

1. 打开应用，允许相机权限（麦克风可选），首次启动有出行安全提示；
2. **请停车后操作，或使用支架固定手机**——出行途中手持手机操作违反当地交通法规；
3. 需要记录时：先点录制，再让画面进入取景范围；到点自动停止；
4. 结果页显示文件路径 / 大小 / 时长，视频保存在系统相册，按接收方的要求直接分享或上传即可。

## 常见问题

- **时间是怎么进到视频里的？** 通过 CameraX 的画面叠加通道，在视频编码前把文字绘制进每一帧，再由编码器合成进 H.264 码流。不是播放时叠加的字幕，删掉应用、换个播放器，时间依然在画面里。
- **时间会被篡改吗？** 时间取自系统时钟、按北京时间格式化，应用内没有任何手动改时间的入口。
- **为什么 30 秒档会弹提示？** 部分提交渠道建议视频短于 20 秒，30 秒档可能超出建议时长，建议优先用 20 秒档。
- **视频保存在哪？** 系统相册「ReportCam」相册 / `Movies/ReportCam/` 目录，文件名按拍摄时间命名。
- **我的机型能用吗？** 应用不做机型白名单，主流 Android 8.0+ 机型均可使用；但 Android 机型碎片化，个别机型可能出现画质档位受限、变焦档位缺失等情况。**录制开始约 1.5 秒后应用会自检时间水印是否真正写入画面，一旦异常会当场红字提示「时间水印可能未生效」，看到红字请直接重录**，不要提交该视频；如遇极端兼容性问题导致视频不可用，可改用系统相机拍照/录像留证，并欢迎在 Issues 反馈机型信息。

## 已知限制

- 退出后台会立即停止录制（避免"不知情录像"的隐私争议）；
- 不做电子防抖/增稳——增稳会改变原始像素，可能与"原件"要求冲突；
- 设备不支持 1080P 时按能力自动降级，极端情况下画面清晰度可能不足以辨认细节；
- 部分机型系统 Geocoder 不可用时，位置水印改为烧录经纬度数字（同样是有效信息）。
